## Featured Project: FixitBhai

### [FixitBhai — Local Service Technician Directory](https://github.com/ShashankS1011/FixitBhai)
A production-ready Android application built using **Java and Material 3** that automatically scans, categorizes, and organizes local service technicians from device contacts and cloud directories.

- **Key Capabilities:** Real-time search, family contact exclusions, dynamic category filtering, offline-first SQLite persistence, cloud synchronization, direct WhatsApp quick actions, and single-click calling.
- **Tech Stack:** Java, Android Material 3, SQLite, Firebase Auth, Firestore, GitHub Actions CI/CD.
- **Releases:** [Download Latest APK & AAB Releases](https://github.com/ShashankS1011/FixitBhai/releases/latest)
